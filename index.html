Claudio backup tool · uso personal / personal use

Qué es. Claudio es una aplicación personal de organización (estudio, hábitos, finanzas y calendario) que corre en el ordenador de su propietario. Esta página existe solo porque Google la pide para registrar el acceso a Google Drive que usa la herramienta rclone para guardar copias de seguridad cifradas.

What it is. Claudio is a personal organiser app that runs on its owner's own computer. This page only exists because Google requires one to register the Google Drive access that the rclone tool uses to store encrypted backups.

Es una app privada de una sola persona: no se distribuye ni está abierta a otros usuarios. No recoge datos de nadie.

This is a private, single-user app: it is not distributed to or open to other users, and it collects no data from anyone.
